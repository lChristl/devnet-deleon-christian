A running log of small things you learn along the way — not a full topic,
just quick notes whenever something clicks or trips you up. Add to this

9/27/2026 - TIL that when I have made a new branch in my local repository, just doing
ordinary git push wont show in my GitHub repository. What I have to do for example is 
git push -u origin (the branch that I created). This pushes the branch that I created
into the original project repository.
