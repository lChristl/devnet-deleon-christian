--- First let me tell you what are these two all about, so basically GitHub is the platform or website where all of your repositories are stored, what are repositories you may ask?
Repositories are something you could relate to a google drive folder, wherein you can place your files there, in our case we mostly put our code files in there. Next is Git so what is Git? Git is a version control for our repositories in which we can keep track of updates, changes, contributions in our repository. It is a useful tool that we can use to manage our repository be it individually or collaboratively. So how helpful would it be for collaborative tasks? You can basically work on your own respective group's repository since you can make branches which could be different features for your system. Basically you would have a stable main branch then a different feature branch that you would merge into the main branch after confirming that it runs smoothly.

## Key vocabulary (in your own words)

- repository: A container where you put your codes
- commit: Places your changes in Git
- branch: Parallel versions of code 
- push / pull: 'push' is to commit your changes to your repository while 'pull' is to grab the repository's latest changes if your local repository or branch is behind.
- pull request: This is how your branch gets merged to the main branch, you should review and test the code before merging pull request, adding description to these pull requests would help in keeping track of what changes are made.
